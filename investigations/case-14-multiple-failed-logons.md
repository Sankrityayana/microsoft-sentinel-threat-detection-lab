
# CASE-14 — Multiple Failed Logons Investigation

## 1. Incident Overview

| Property | Value |

| Classification | Informational, expected activity |
| Determination | Security testing |

## 2. Detection Context

The incident was generated by the scheduled analytics rule:

`SOC Lab - Multiple Failed Logons`

The rule identifies five or more failed authentication attempts against the same account and computer within a five-minute time window.

## 3. Triggering Activity

A controlled authentication test was performed using an intentionally incorrect password.

The test generated seven failed logon events for:

`windows-lab-vm\SOC_Lab_InvalidUser_9281`

## 4. Event Evidence

| Field | Observed value |
|---|---|
| Event ID | 4625 |
| Computer | `windows-lab-vm` |
| Account | `windows-lab-vm\SOC_Lab_InvalidUser_9281` |
| Failed attempts | 7 |
| Source IP | `::1` |
| Logon type | 3 |
| Event description | An account failed to log on |

## 5. Investigation

The underlying Windows Security events were examined to establish the account, computer, event type and source address.

The observed activity was correlated with the intentionally generated invalid-password test.

The source address `::1` is the IPv6 loopback address, consistent with the local test environment.

## 6. Findings

- Seven failed authentication attempts were observed.
- All were associated with the controlled test account.
- The events originated from the monitored lab VM.
- The activity matched the controlled testing procedure.
- The evidence supported classification as expected security testing.

## 7. Classification and Determination

| Field | Value |
|---|---|
| Classification | Informational, expected activity |
| Determination | Security testing |
| Final status | Resolved |

## 8. Analyst Investigation Comment

The following investigation note was recorded:

> Investigated Windows Security Event ID 4625 on windows-lab-vm. The activity consisted of seven failed logon attempts against the controlled test account. The events were intentionally generated using an invalid password as part of SOC lab testing. Classified as expected security testing activity.

## 9. Investigation Conclusion

The detection successfully identified repeated failed authentication attempts exceeding the configured threshold.

The underlying events were consistent with the controlled test. The incident was classified as expected security testing and resolved.

No conclusion about a real-world attack or compromise is implied by this test.
