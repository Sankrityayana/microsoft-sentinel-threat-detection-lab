## 2. Detection Context

The incident was generated by the scheduled analytics rule:

`SOC Lab - Suspicious PowerShell Activity`

The detection examines PowerShell Script Block Logging events for selected indicators, including `FromBase64String`.

## 3. Controlled Test Activity

A benign PowerShell script was executed to test Base64 decoding visibility.

```powershell
$encoded = "SGVsbG8="
$decoded = [System.Text.Encoding]::UTF8.GetString(
    [Convert]::FromBase64String($encoded)
)
Write-Output "SOC_LAB_BASE64_TEST: $decoded"
```

Observed output:

`SOC_LAB_BASE64_TEST: Hello`

## 5. Investigation

The investigation examined the underlying PowerShell script block event separately from the Sentinel incident overview.

The script used a Base64 value that decoded to the plain-text string `Hello`.

The observed activity was correlated with the intentionally executed test script.

No evidence of malicious download activity or external network communication was identified in the investigated test. This conclusion is limited to the reviewed test activity and telemetry.
