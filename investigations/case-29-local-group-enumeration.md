## 2. Detection Context

The incident was generated by the scheduled analytics rule:

`SOC Lab - Suspicious Local Group Enumeration`

The detection identifies PowerShell-based enumeration of selected privileged local groups, including Administrators and Remote Desktop Users.

## 3. Controlled Test Activity

The following PowerShell command was executed on the Windows Server VM:

```powershell
Write-Output "SOC_LAB_GROUP_ENUM_TEST_START"

Get-LocalGroupMember -Group "Administrators" |
    Select-Object Name, ObjectClass, PrincipalSource

Write-Output "SOC_LAB_GROUP_ENUM_TEST_END"
```

Observed output:

`windows-lab-vm\lab-user User Local`

The purpose was to verify that local group enumeration generated the expected Windows Security telemetry.

## 4. Event Evidence

Two Event ID 4799 records were identified.

| Field | Observed value |
|---|---|
| Event ID | 4799 |
| Computer | `windows-lab-vm` |
| Associated account | `LAB\windows-lab-vm$` |
| Caller process | `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe` |
| Target group | Administrators |
| EventRecordIds | 46443, 46444 |
| Matching events | 2 |

## 5. Investigation

The underlying SecurityEvent records were examined to identify the caller process, target group, account and event identifiers.

Both events recorded PowerShell enumeration of the local Administrators group.

The activity was correlated with the controlled `Get-LocalGroupMember` test performed on the VM.

## 6. Findings

- Two matching Event ID 4799 records were observed.
- Both events were associated with the PowerShell executable.
- Both targeted the local Administrators group.
- The events corresponded to the controlled enumeration test.
- The incident was classified as expected security testing.
- No evidence of unauthorized group modification or account compromise was identified in the investigated activity.
